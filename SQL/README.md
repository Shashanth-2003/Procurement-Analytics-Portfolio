# SQL Queries

Database: MySQL Workbench  
Dataset: 200 purchase orders across 15 vendors

## Queries Included
1. Top 5 vendors by total expenditure
2. Total spending by department and category
3. Vendor discount analysis with percentage calculation
4. Delivery status tracker with CASE statement categorisation
5. Monthly spend trend analysis
6. Department savings and average PO value comparison

## Key Concepts Used
- GROUP BY and ORDER BY
- CASE statements for conditional categorisation
- STR_TO_DATE for date comparisons
- Calculated fields (discount percentage, delay days)
- LIMIT for top N analysis
