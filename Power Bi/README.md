# Power BI Dashboard

## Pages
**Page 1: Spending Overview**
- 6 cards (Total POs, Vendors, Departments, 
  Categories, Total Spend, Total Savings)
- Clustered bar chart: Department spending by category
- Pie chart: Department spend share
- Vendor slicer with multi-select bookmark

**Page 2: Vendor Performance**  
- Horizontal bar chart: Vendor spend ranking
- Horizontal bar chart: Vendor discount amounts
- Scatter plot: Total spend vs discount percentage

**Page 3: Vendor Drill Through**
- Accessible from Page 2 via Drill Through button
- Individual vendor card (Categories,Quantities,Total PO's,Discount Percentage)
- Order status breakdown (Delivered/Pending/
  In Transit/Cancelled)
- Gauge charts for expenditure and savings
- Department spend distribution chart

## Features
- Cross-page drill through navigation
- Back button for return navigation
- Interactive vendor filtering
- Responsive tooltips
